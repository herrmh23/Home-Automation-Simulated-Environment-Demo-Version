# Home-Automation-Simulated-Environment-Demo-Version
This is a demo version of my Smart Home application. This app was built for a semester long group project for my Computer Programming II course at UWGB. This version allows for easy download and use for demonstration purposes. The full version presented to my class includes login and user type features.

The demo version of this project is meant to be used to show off the features of my Home Automation Simulated Environment in a simple manner. The differences between this verion and the full version are:
1. The demo version does not have user creation or user sign in features
2. The demo version does not have system persistence (changes will not be saved when the app is closed)
3. The demo verion uses the main to prelaod a rooms, devices, and a rule

When deploying this application, note that JavaFX 25.0 was used to build the front end. The name of the main is "SmartHomeProject.java"
